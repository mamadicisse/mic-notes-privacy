Politique de confidentialité — MIC Notes

Dernière mise à jour : 8 novembre 2026

MIC Notes est une application de prise de notes conçue par Mamadi Cissé. Cette politique explique quelles données l'application utilise et comment elles sont protégées.

En résumé

  • Aucune donnée n'est collectée par le concepteur ni transmise à un serveur.
  • Toutes vos notes restent uniquement sur votre appareil.
  • L'application ne contient ni publicité, ni outil de statistiques, ni traceur.

Données enregistrées sur votre appareil

L'application enregistre localement, dans le stockage privé de l'application :

Donnée Utilisation
Nom de la session Personnaliser l'affichage (salutation, profil)
Notes, listes, catégories, couleurs Fonctionnement de l'application
Code PIN Protéger l'accès à la session
Questions de sécurité et réponses Réinitialiser le code PIN en cas d'oubli
Préférences (thème, tri, affichage) Mémoriser vos réglages

Le code PIN et les réponses aux questions de sécurité ne sont jamais enregistrés en clair : seule une empreinte cryptographique (SHA-256 salée) est conservée.

Ces données ne quittent pas votre appareil et ne sont accessibles ni au concepteur ni à des tiers.

Partage, export et import

Lorsque vous choisissez d'exporter ou de partager une note (fichier .txt, .docx ou .pdf), le fichier est transmis à l'application que vous sélectionnez (Fichiers, Google Drive, messagerie, e-mail…). Ce transfert est réalisé à votre demande, par le système Android ; les données sont alors soumises à la politique de confidentialité de l'application choisie.

Lors d'un import, l'application lit uniquement les fichiers .txt ou .docx que vous sélectionnez.

Autorisations

MIC Notes ne demande aucune autorisation sensible (pas d'accès à la localisation, aux contacts, à l'appareil photo, au micro ni à l'ensemble de vos fichiers). Les fichiers à importer sont choisis par vous via le sélecteur de fichiers du système.

Conservation et suppression

Vos données sont conservées tant que l'application est installée. Vous pouvez les supprimer à tout moment :

  • Supprimer une note : menu de la note → Supprimer, puis vider la corbeille (les notes en corbeille sont supprimées automatiquement après 30 jours) ;
  • Effacer toutes les notes d'une session : Paramètres → Données → Effacer les notes de la session ;
  • Supprimer une session et ses notes : Paramètres → Supprimer cette session ;
  • Tout supprimer : désinstaller l'application.

Sécurité

L'accès à chaque session est protégé par un code PIN, avec blocage temporaire après plusieurs codes erronés. Le code PIN protège l'accès dans l'application ; il ne chiffre pas le contenu des notes. Nous vous recommandons de protéger aussi votre téléphone par un verrouillage d'écran.

Enfants

MIC Notes ne collecte aucune donnée, y compris auprès des enfants.
